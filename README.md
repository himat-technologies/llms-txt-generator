## 🌈 What you can do

| ✨ Feature | 📝 Details |
|---|---|
| **Start with a template** | Choose a starting point for SaaS, developer APIs, tech blogs, e-commerce, or agency and service websites. |
| **Customize your content** | Edit your site title, summary, documentation sections, and optional AI context. |
| **Generate both formats** | Create `llms.txt` and optionally `llms-full.txt` with live Markdown output. |
| **Check your document** | Validate the required structure and check URLs and links. |
| **Preview as you go** | See a live Markdown preview while editing. |
| **Copy or download** | Copy the generated content or download it as a file. |
| **Keep control of your data** | All processing happens in your browser—no backend or API required. |

## 🚀 Try it

Open the **[HiMat LLMs.txt Generator demo](https://himat.tech/free-toolsllms-txt-generator)** to get started.

## 💻 Run locally

1. Clone or download this repository.
2. Open `index.html` in your browser, or start a local static server:

   ```bash
   python -m http.server 8000
   ```

3. Visit [http://localhost:8000](http://localhost:8000).

## 📁 Project files

| File | Purpose |
|---|---|
| [`index.html`](index.html) | App structure |
| [`styles.css`](styles.css) | Styling and layout |

## 🔒 Privacy

Your content stays in your browser. The generator does not send user-entered information to a backend or external service.
